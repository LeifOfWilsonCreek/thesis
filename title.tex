\title{The Impact Of Pit On Security And Portability}

\date{\today}
\maketitle

\begin{abstract}
	Pit\cite{pit,2006pedersen} is a general-purpose language designed to be an
	alternative to C.  Its expressive ability is a superset of C, and it easily
	interoperates with C and assembly language, making it no less suitable than C
	for low-level programming.

	Its additional features allow the programmer to easily guarantee that there are
	no buffer or integer overflow vulnerabilities by automating memory allocation,
	with some cost to efficiency.  Manual memory allocation is still well-supported
	for when the cost to efficiency is too great or, for example, in parts of a
	kernel where automatic allocation is impractical.

	The additional features also make it practical to write source files that are
	still portable between operating systems after they are compiled to object
	files, substantially reducing the amount of work required to move an
	application from one operating system to another.

	These additional features are also more widely applicable; they provide an
	infrastructure for managing complex data structures and abstract data types
	easily.  This paper focuses on the applicability of Pit to security and
	portability, as these are important issues that Pit can have a significant
	impact on.
\end{abstract}
